# About display-gift-image-extension
- The extension supports displaying the gif image when load a website.
- The extension is developed by Tuan Nguyen.

## Features
- Overlays an animated GIF character on any webpage as it loads.
- Popup lets you pick the GIF source — a random GIF, or search Giphy by keyword — and which corner of the screen it's positioned in.
- Turn the overlay on/off from the popup without losing your saved settings.
- Clear your saved settings at any time from the popup.

## How to use
1. Click the extension icon to open the popup.
2. Choose **Random Gif** or **Search Gif By Key** (enter a keyword) and a screen position, then click **Save** — the current tab reloads to apply it.
3. Use **Off**/**On** to toggle the overlay for future page loads, or **Clear** to reset all saved settings.
