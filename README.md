# Extensions Development
- [TIKI360 extension](https://github.com/nguyenvantuan2391996/extensions-development/tree/master/tiki360-extension): The extension supports getting Tiki360's information: token, customer id, order code,...and auto-buy insurance.
- [Detector APIs extension](https://github.com/nguyenvantuan2391996/extensions-development/tree/master/detector-apis-extension): The extension supports getting all APIs and CURL command when load a website.
- [Display gif image extension](https://github.com/nguyenvantuan2391996/extensions-development/tree/master/display-gif-image-extension): The extension supports displaying the gif image when load a website.
- [Password generator extension](https://github.com/nguyenvantuan2391996/extensions-development/tree/master/password-generator-extension): The extension supports generating random password strongest.
- [Bubu Dudu GIF picker extension](https://github.com/nguyenvantuan2391996/extensions-development/tree/master/bubu-dudu-gif-picker-extension): Bubu Dudu GIF Picker Extension is a simple and cute Chrome extension that lets you browse, add, and select your favorite GIFs with just one click.
- [Chess game extension](https://github.com/nguyenvantuan2391996/extensions-development/tree/master/chess-game-extension): The extension supports playing chess right from the toolbar - 2 players or vs. a Minimax + Alpha-Beta AI, with autosaved progress and win/loss stats.
- [Flappy Bird extension](https://github.com/nguyenvantuan2391996/extensions-development/tree/master/flappy-bird-extension): The extension supports playing Flappy Bird right from the toolbar - tap/Space to flap yourself, or watch a Q-learning AI teach itself to play.
- [Audition extension](https://github.com/nguyenvantuan2391996/extensions-development/tree/master/audition-extension): The extension supports playing an Audition-style rhythm dance game right from the toolbar - 4K/8K/Beat-up modes, using only music you pick from your own computer.
- [2048 extension](https://github.com/nguyenvantuan2391996/extensions-development/tree/master/2048-extension): The extension supports playing 2048 right from the toolbar - merge matching tiles with arrow keys, WASD, or swipes to reach 2048, with autosaved best score.
- [Basketball extension](https://github.com/nguyenvantuan2391996/extensions-development/tree/master/basketball-extension): The extension supports playing Basketball right from the toolbar - drag to aim and shoot, score baskets within 40 seconds, and land a clean swish for a bonus point.
- [Beer Catch extension](https://github.com/nguyenvantuan2391996/extensions-development/tree/master/beer-catch-extension): The extension supports playing Beer Catch right from the toolbar - move the glass to catch falling beer, dodge broken glass shards, and chase a new high score.
