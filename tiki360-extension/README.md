# About tiki360-extension
- The extension supports getting Tiki360's information: token, customer id, order code,...and auto-buy insurance.
- The extension is developed by Tuan Nguyen.

## Features
- One-click copy of the signed-in customer's token, customer ID, and email from the current tab.
- On an insurance contract-info page, surfaces the order code, policy ID, and booking code, each with a copy button.
- On a storefront product page, surfaces the product ID/SKU/name and any bundled add-on's ID/name.
- Detects `ds-insurance` API calls made by the page and lists them with status/request ID, each copyable as a CURL command.
- Auto-buy flows for embedded, bike/car, and travel insurance products, plus binding an add-on to the current product — each walks through cart/shipping/payment/checkout automatically and reports progress at every step.
- Guards against running auto-buy actions outside the Tiki dev environment.

## How to use
1. Navigate to a supported Tiki page (dev or production) and sign in.
2. Click the extension icon — it reads your token/customer info automatically and shows page-specific details (insurance contract or storefront product).
3. Use the copy buttons to grab any field, or pick an auto-buy action to run through checkout for that product type.
